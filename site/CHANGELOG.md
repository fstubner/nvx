# Changelog

All notable changes to this product are documented here. The file follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

A version heading carries a date only once its release is tagged; the
changelog page relays exactly that, and `npm run check:changelog` fails a
dated heading that has no matching `vX.Y.Z` tag.
